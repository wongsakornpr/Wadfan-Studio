กำหนดขนาด ตัวเลือก และราคา (Variants)

เพิ่มขนาดรูปภาพที่แตกต่างกัน หรือชุดแพ็กเกจใบงานพร้อมกำหนดราคาของแต่ละขนาด

ตั้งค่าการเชื่อมต่อฐานข้อมูล Supabase

นำ Project URL และ Anon Public API Key จากหน้า Dashboard ของ Supabase (Settings > API) มากรอกที่นี่ เพื่อบันทึกข้อมูลจริงเข้าสู่ระบบคลาวด์ของคุณ

วิธีติดตั้งตาราง (SQL Script):

หากคุณเพิ่งสร้างโปรเจกต์ Supabase ใหม่ อย่าลืมกดเปิดดู "สคริปต์ SQL Supabase" แล้ว Copy ไปวางในเมนู SQL Editor บนเว็บ Supabase แล้วกด Run หนึ่งครั้ง เพื่อสร้างตารางสินค้าและตัวเลือกขนาดครับ

สคริปต์ SQL สำหรับสร้างตารางบน Supabase

คัดลอกโค้ด SQL ด้านล่างนี้ ไปวางในเมนู SQL Editor > New query บน Supabase Dashboard แล้วกดปุ่ม Run
